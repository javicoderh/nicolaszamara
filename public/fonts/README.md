# Fuentes alojadas en el proyecto

Las dos familias de texto son Italiana (títulos) y Poppins (cuerpo y controles, pesos 400 y 600). Mrs Saint Delafield se utiliza exclusivamente para la composición provisional de la marca manuscrita. Esta composición no sustituye el archivo original de la firma de Nicolás.

Origen: repositorio oficial [google/fonts](https://github.com/google/fonts), directorios `ofl/italiana`, `ofl/poppins` y `ofl/mrssaintdelafield`. Las tres familias se distribuyen bajo SIL Open Font License; sus licencias originales están junto a los archivos TTF. Se conservan sin modificar y se sirven desde el mismo dominio.
