# Fotografías de terapias

Las dos imágenes son las capturas facilitadas por el usuario en `fotos estilo web`:

- `services-top.jpeg`: `WhatsApp Image 2026-10-21 at 13.52.21.jpeg`.
- `services-bottom.jpeg`: `WhatsApp Image 2026-10-21 at 13.52.21 (1).jpeg`.

`TherapyCard` muestra únicamente cada fotografía circular mediante un viewport CSS. El resto de las capturas queda oculto. Las coordenadas están en `therapyServices`, dentro de `src/content/siteContent.js`. Las imágenes originales no se modifican; su nitidez está limitada por la captura. Se pueden sustituir por fotografías originales cuando se faciliten.
